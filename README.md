**CodeAlpha Frontend Development Internship Projects**

This repository holds the projects I built during my frontend development internship at CodeAlpha. I used HTML, CSS and JavaScript for all of them, and each one helped me practice turning a simple idea into a working web page.

 **Image Gallery**

I built an image gallery where you can browse pictures and open a preview of each one. It is made with index.html, style.css and script.js. I also wrote a short document about it called Image Gallery Preview.docx, and the whole project is available in Image Gallery.zip.

## Basic Calculator

This is a simple calculator that handles everyday arithmetic right in the browser. The code lives in calculator.html, calculator.css and calculator.js. My notes on it are in Basic Calculator.docx, and there is a zipped copy in Basic calculator.zip.

## Portfolio Website

I also put together a personal portfolio website using portfolio.html, portfolio.css and portfolio.js. The write-up is in Portfolio.docx, and a zipped copy is in Portfolio Site.zip.

## How to run them

Download or clone this repository, then open the HTML file of the project you want in any browser. Open index.html for the image gallery, calculator.html for the calculator and portfolio.html for the portfolio.

## What I learned

These were beginner projects, and they taught me how to structure a page with HTML, style it with CSS and make it interactive with JavaScript. They gave me a good feel for how a website comes together.
